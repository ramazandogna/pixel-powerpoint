- Japan averages are from the NTA 民間給与実態統計調査 (2023): all workers ¥4.6M, regular employees ¥5.3M, 情報通信業 ¥6.49M (the industry figure comes from a secondary summary).
- HENNGE ¥5.5M is the team's figure (company-wide average). Check the latest 有価証券報告書.
